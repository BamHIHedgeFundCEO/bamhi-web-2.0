# RRG 相對輪動圖 — 原理與判讀

本專案 RRG 的完整說明。公式、判讀方式、已知限制。
所有數字都對應 `backend/services/sector_rotation.py` 的實際程式碼,不是理論值。

---

## 1. 一句話

RRG 把 41 個主題板塊**相對 SPY 的強弱趨勢**畫在二維平面上:
X 軸 = 相對強弱正在變好還是變壞,Y 軸 = 這個變化正在加速還是減速。
點的**實心/空心**額外表達該板塊的**絕對**趨勢。

---

## 2. 原理

### 2.1 板塊指數怎麼來

不是 ETF,是自己合成的。每個板塊取成分股的**等權日報酬**累乘(`sector_rotation.py:120-127`):

```python
ret_close = ((data[valid] - prev_close) / prev_close).clip(-0.95, 2.0)
sector_index = ((1 + ret_close.mean(axis=1).fillna(0)).cumprod() * 100)
```

**等權不是市值權重。** 差別很大:市值權重的「AI 板塊」實質上就是 NVDA 一檔;等權測的是主題**廣度** —— 主題是不是真的擴散到多數成分股。這是刻意的設計選擇。

代價:這個指數**不可交易**,沒有對應的 ETF。它是觀測工具,不是標的。

### 2.2 相對強弱線 RS

```python
spy_price = data["SPY"]
rs_raw = sector_index / spy_price          # :134
rs_line = rs_raw / rs_raw.dropna().iloc[0] # :135 首日歸一化
```

RS 上升 = 板塊跑贏 SPY。RS 下降 = 跑輸。**注意:RS 上升不代表板塊在漲**,只代表它比 SPY 好。這是後面所有陷阱的根源。

（`:135` 那行歸一化對 RRG 兩軸是**數學上的 no-op** —— 比值對常數縮放不變。它只影響 `RS_Line` 圖與 `RS_Slope`。）

### 2.3 X 軸:RS_Ratio

```python
RRG_SHORT, RRG_LONG = 14, 50               # :23-24
rs_ratio = (rs_line.rolling(14).mean() / rs_line.rolling(50).mean()) * 100   # :143
```

$$\text{RS\_Ratio}_t = 100 \times \frac{\mathrm{MA}_{14}(\text{RS})_t}{\mathrm{MA}_{50}(\text{RS})_t} = 100 + 100\cdot\frac{\mathrm{MA}_{14}-\mathrm{MA}_{50}}{\mathrm{MA}_{50}}$$

分子分母**都是同一條 RS 線**,只差窗口長度(14 日 vs 50 日交易日)。

- X > 100 → RS 的短期均線在長期均線上方 → 相對強弱處於**上升趨勢**
- X = 100 → 兩條均線交會 → 相對強弱走平
- X < 100 → 相對強弱處於下降趨勢

**X 衡量的是趨勢方向,不是水位。** 一個板塊過去兩年相對 SPY 超額 +60%,但近三個月走平 → X ≈ 100,掉到中軸。它**不告訴你「累積跑贏多少」**。

100 中軸的來源:MA14 = MA50 時比值 = 1.0,`* 100` = 100。**沒有 z-score、沒有 min-max、沒有標準化**,`:143` 尾端的 `* 100` 是唯一轉換。所以 X 的數值可以直接讀:X = 108 就是「14 日均線比 50 日均線高 8%」。

### 2.4 Y 軸:RS_Momentum

```python
rs_momentum = (rs_ratio / rs_ratio.rolling(14).mean()) * 100   # :144
```

$$\text{RS\_Momentum}_t = 100 \times \frac{\text{RS\_Ratio}_t}{\mathrm{MA}_{14}(\text{RS\_Ratio})_t}$$

是 **RS_Ratio 相對自己 14 日均線的位置**,不是 ROC、不是差分。

Y > 100 → X 正在往上推進(加速);Y < 100 → X 正在減速。

**有效回看約 6.5 個交易日,不是 14 天。** MA14 的重心在 $(14-1)/2 = 6.5$ 日前,所以 Y 測的是 X 相對於約 6.5 日前的偏離。Y 比 X 靈敏得多。

### 2.5 四象限

```python
def rrg_quadrant(rs_ratio, rs_momentum):   # :303-310
    if rs_ratio > 100 and rs_momentum > 100:  return 領先 Leading
    if rs_ratio > 100:                        return 轉弱 Weakening
    if rs_ratio <= 100 and rs_momentum <= 100: return 落後 Lagging
    return 改善 Improving
```

翻成白話成立條件:

| 象限 | 條件 | 意思 |
|---|---|---|
| 🟢 領先 | MA14(RS) > MA50(RS) 且 X 高於自己 14 日均線 | 相對強弱在上升趨勢,且還在加速 |
| 🟡 轉弱 | MA14(RS) > MA50(RS) 但 X 低於自己 14 日均線 | 相對趨勢仍在,但近 ~6.5 日開始減速 |
| 🔴 落後 | MA14(RS) < MA50(RS) 且仍在惡化 | 相對強弱下降且持續變差 |
| 🔵 改善 | MA14(RS) < MA50(RS) 但 X 開始回升 | 仍在下降趨勢,但可能正在打底 |

理想循環是**順時針**:改善(左上)→ 領先(右上)→ 轉弱(右下)→ 落後(左下)→ 改善。

### 2.6 實心/空心:絕對趨勢維度

X、Y 都除過 SPY,**絕對價格資訊被消掉了**。所以額外加一個旗標(`:313-326`):

```python
def _abs_trend_up(df):
    return bool(last["Sector_Close"] > last["MA60"] > last["MA200"])
```

- **實心** = 指數 > MA60 > MA200 → 絕對趨勢確認多頭
- **空心** = 不滿足 → 絕對趨勢未確認(可能橫盤,可能在跌)
- MA200 資料不足時回 `None` → 前端退回實心樣式,此資訊失效

用 MA60 而非 MA50,因為 DataFrame 只算了 `MA10/MA20/MA60/MA120/MA200`(`:162-164`),與訊號卡 `_signal_from_df` 已在用的 MA20>MA60 同族。

## 3. 怎麼用

### 3.1 判讀順序(照這個順序看,不要跳)

1. **先看實心/空心,不是先看象限。** 空心點不管落在哪裡都先降權。
2. **實心 + 領先象限** → 真正的強勢板塊,值得往下鑽成分股(下方 VCP 清單)。
3. **實心 + 改善象限** → 潛在輪動候選,絕對趨勢已站穩、相對強弱剛翻正。訊號較早,風險也較高。
4. **空心 + 領先象限** → **陷阱區**。跌得比大盤少也會被畫在這裡。不是買點。
5. **實心 + 轉弱象限** → 絕對趨勢還在,但相對動能在退。已持有可續抱並收緊停損,不加碼。
6. **空心 + 落後象限** → 明確迴避。
7. 最後看軌跡 tab 確認方向:連續往右上 > 單點位置。

### 3.2 全覽四個 Tab 各看什麼

| Tab | 用途 |
|---|---|
| 熱力圖 | 顏色 = M10 − M20,找短線動能加速的板塊。最快的初篩 |
| RRG 象限快照 | 當下所有板塊的相對位置 + 絕對趨勢(實心/空心) |
| RRG 軌跡 | 最近 5/10/15/20 交易日的路徑。看方向,不看位置 |
| 相關係數 | 選出的多個板塊是否同漲同跌。同向板塊不具分散效果 |

點任一板塊的點 → 自動跳轉下方深度分析。

### 3.3 區間怎麼選

| 區間 | 交易日 | 能不能用 |
|---|---|---|
| 6mo | ~126 | RRG 可用,但**MA200 不足 → 實心/空心失效** |
| 1y | ~250 | 全部功能可用 |
| **2y** | ~500 | **建議值**,也是唯一有預算 JSON 的區間(秒開) |
| 5y+ | — | 可用,但需即時計算(慢),且軌跡仍只有 20 點 |

`2y` 走 `data/sector_rotation/*.json` 預算檔(`:49-54`),其他區間會觸發即時 yfinance 下載數百檔,明顯變慢。

### 3.4 暖機期(實測)

`rolling` 預設 `min_periods = window`,所以:

| 產出 | 需要交易日 |
|---|---|
| RS_Ratio 第一個值 | 50 |
| RS_Momentum 第一個值 | 50 + 13 = **63** |
| 圖上第一個點(需兩者都有) | **63**(≈ 3 個月) |
| 預設 10 點軌跡 | 63 + 9 = **72** |
| 完整 20 點軌跡 | 63 + 19 = **82**(≈ 4 個月) |
| 實心/空心(需 MA200) | **200** |

50~62 天之間會**一個點都畫不出來**(`:406` 對兩軸同時 dropna)。

## 4. 已知限制(必讀)

### 4.1 兩軸都是純相對指標,不含絕對漲跌

大盤跌 30%、板塊跌 10% → RS 上升 → 落在**領先象限**。板塊實際在虧錢。

這是所有相對指標(含標準 RRG)的通病,**本專案的公式沒有迴避它**。實心/空心旗標是用來**看穿**這個陷阱,不是消除它。真實例子(2y,MA60/MA200):

```
電力公用事業  X=100.73 Y=100.23 領先象限  但 Close=169.70 MA60=166.07 MA200=167.50 → 空心
```

領先象限 + 空心 = 抗跌,不是強勢。

### 4.2 沒有波動度正規化 → X 的絕對值混入 beta

標準 RRG 會把振盪值除以滾動標準差,本專案沒有(`:143` 只有 `* 100`)。後果:高波動主題籃的 X 天生跑得更遠。

實測:極端值全是高波動籃(資安 110.96、太空 79.07),中軸附近全是低波動籃(電力公用 98.37、電網 97.51)。

**所以不要單純用 X 排序決定部位大小** —— 那部分在用 beta 排序。

### 4.3 標的池不 spanning SPY → 壓力期會集體偏左

標準 RRG 用市值加權的 GICS sector ETF,加總 ≈ SPY,RS 平均被結構性釘在 1.0,必然左右分裂。

本專案 41 個手選主題籃整體 beta > 1、等權、不覆蓋 SPY 全部權重,**沒有這個錨**。實測現況(period=2y):

```
41 個板塊:X > 100 只有 9 個,32 個(78%)在中軸左側,X 中位數 95.11
象限分布:落後 26 / 改善 6 / 轉弱 6 / 領先 3
```

大盤真的大跌時會更極端。**當 78% 的點擠在左下,落後象限就失去區辨力**,實際可用資訊只剩「右側那幾個是誰」。

### 4.4 軌跡只有 20 個交易日,看不到旋轉

`:413` 硬切 `v.iloc[-20:]`,即使區間設 10y 也一樣。20 日 ≈ 4 週。

RRG 的核心賣點「順時針旋轉」是數月尺度現象,標準版常看 10~12 **週**。4 週日線畫出來的是雜訊折線。**軌跡 tab 只能當短期方向確認,不要當旋轉週期判讀。**

### 4.5 Y 軸過度靈敏 → 象限跳動主要來自 Y

實測 X 分散度 ±20、Y 只有 ±10,而 Y 的有效回看只有 ~6.5 日。結果:領先 ↔ 轉弱 高頻來回,領先 ↔ 改善(跨 X 軸)很罕見。

**跨 Y 軸的象限變化不要當成訊號**,要看 X 有沒有真的移動。

### 4.6 這不是 alpha 來源

四階段審查的結論:公式層面本專案與標準 RRG 互有勝負,大概率沒有統計顯著差異。RRG 是**視覺化與敘事工具**,用來看懂資金流向,不是買賣訊號產生器。

實際的訊號來源是下方的 **VCP 清單** 與首頁的 **訊號卡**(`_signal_from_df:326-345`,要求「領先象限 **且** Close > MA20 > MA60」才給綠燈)。RRG 負責告訴你**去哪個板塊找**。

### 4.7 資料細節

- `yf.download(..., auto_adjust=False)`(`:88`),取未調配息的 `Close`(`:110`)。實測對 X 的影響平均 0.06~0.12 點、最大 0.36 點(X 跨度 ±20),**可忽略**。累積型輸出(`RS_Line` 圖、`rs_3m`)受影響較大(高配息籃 2 年被低估 ~2.2-2.7%)
- 基準 **SPY 硬編碼**,不可更換;缺 SPY 直接回 `None`(`:113`)
- 資料頻率**日線**,無 resample。所有 `rolling` 窗口單位都是交易日

## 6. 維護重點

本專案 RRG 相對標準版真正的優勢**不在公式,在 `sector_config.py` 的 41 個主題籃**。
GICS 只有 11 個板塊,「量子計算」「算力租借」「太空」在 GICS 裡全被埋在 XLK 底下。

所以維護資源應該花在:**成分股清單的正確性與分類粒度**,不是調 `RRG_SHORT` / `RRG_LONG`。
